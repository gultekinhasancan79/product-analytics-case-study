# Experiment Review Checklist

Before a treatment decision is communicated, this case study verifies:

- [x] randomization unit and metric hierarchy are defined,
- [x] sample-size / MDE assumptions are explicit,
- [x] sample-ratio mismatch is checked,
- [x] pre-treatment balance is reviewed,
- [x] the primary effect includes a confidence interval,
- [x] guardrails are evaluated separately from the primary outcome,
- [x] exploratory subgroup differences use an interaction test,
- [x] event-level funnel evidence reconciles with user-level outcomes,
- [x] data-quality rules run before analysis,
- [x] the committed decision report is regenerated in CI.
